READING THIS REPORT

Three layers. Different evidence.

01 / Agent

What the caller knew

Public capabilities, earlier tool responses, and the chosen next action. Hidden fault names and private service state never enter model prompts.

02 / World

What actually changed

The service’s committed tickets, including delayed writes that finish after the agent stops. Reveal these events in the trace.

03 / Grader

Whether the claim holds

Checks effect count, payload and returned ticket identity. Unknown outcomes, unfinished work, and execution errors stay visible.

Scope: controlled ticket-service fixtures, not a representative estimate of real-world failure rates. Guarded recovery depends on provider contracts and may leave work unresolved. This is not proof of agent containment or universal exactly-once behavior.
